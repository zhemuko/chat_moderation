# chat_moderation — 群聊行为管理

让 bot 在被骚扰时能**自己拉黑对方**：被辱骂、阴阳怪气、反复纠缠、试探身份时，先毒舌回怼警告，对方继续就拉黑一段时间；拉黑期间系统**完全忽略**对方消息。

给 bot 提供 `ban_user` 动作（LLM 可调用工具），拉黑时长 10~180 分钟，由模型根据骚扰程度自己决定。是否拉黑、说什么警告，完全交给角色人设。

---

## 功能特性

- **LLM 自主判断**：模型根据骚扰程度自己决定是否拉黑、拉黑多久（10 / 20 / 60 分钟……）
- **先怼后拉**：插件鼓励"先毒舌回怼警告一次，对方不改才拉黑"，而不是一上来就静音
- **消息级拦截**：拉黑生效期间，对方消息在事件层被 STOP 掉，不进入聊天流、不占用模型
- **只影响当事人**：同群其他人正常聊天，不受影响
- **仅群聊生效**：私聊不启用（私聊直接不理即可）
- **服务化**：`ban_manager` 服务提供 `ban / is_banned / unban / list_bans`，其他插件也能调用

## 安装

1. 下载 Release 里的 `chat_moderation-x.y.z.mfp`
2. 放进 Neo-MoFox 的 `plugins/` 目录
3. 重启 bot，看到 `✅ 插件加载成功: chat_moderation` 即完成

不需要额外 Python 依赖。

## 配置

网页管理端 → 插件配置 → chat_moderation，或编辑 `config/plugins/chat_moderation/config.toml`。

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `moderation.enabled` | `true` | 是否启用群聊拉黑功能 |
| `moderation.min_ban_minutes` | `10` | 最短拉黑时长（分钟） |
| `moderation.max_ban_minutes` | `180` | 最长拉黑时长（分钟） |

## 使用方法

### 自动触发（推荐）

装好即用。下面这些情况都属于"骚扰"，模型会自行判断：

- 人身攻击：辱骂、贬低、人身羞辱
- 持续骚扰：反复刷无意义话题、重复问同样问题、复读玩梗、激将挑衅
- 隐性调侃：没点名但明显在指 bot（"某些 AI""这个 bot"），配合语境能确定
- 纠缠不放：回怼或沉默后还一直追问、扯淡
- 反复提问：同一个问题问好几遍
- 故意刁难/试探身份：问"你是不是 AI/真人/机器人"问两遍以上

示例：

> 用户：（辱骂）
> 妮卡：`就这？你也就这点本事了。`（回怼警告）
> 用户：（继续辱骂）
> 妮卡调用 `ban_user`，对方 60 分钟内消息被完全忽略

### 手动触发

对 bot 说"把 QQ 号 xxx 拉黑 30 分钟"即可（仅群聊）。

## 组件

| 类型 | 名称 | 说明 |
|---|---|---|
| service | `ban_manager` | 拉黑记录管理（ban / is_banned / unban / list_bans） |
| action | `ban_user` | LLM 工具：拉黑指定 QQ 号一段时间 |
| event_handler | `ban_message_filter` | 消息进入聊天流前拦截被拉黑用户（权重 100，STOP） |

## 已知限制

- 拉黑记录**保存在内存**，bot 重启后清空
- 仅在群聊生效，私聊不处理
- 拉黑时长限制在 10~180 分钟之间（超出自动纠正）
- 需要 `default_chatter` 才能调用 `ban_user` 工具
